# 桌面快捷连接与学习体验（2026-10-14）

指定浏览器与无手填连接页的最新契约见 [DESKTOP-BROWSER-VIDEO-SPEC.md](DESKTOP-BROWSER-VIDEO-SPEC.md)。

## 连接
- GitHub 默认入口是“连接 GitHub”，显式点击后启动随安装包分发、固定版本且核验官方校验和的 GitHub MCP 服务，以官方 OAuth/PKCE 在用户选定的 Chrome / Edge 授权。无需粘贴 Token；高级 Token 模式保留。
- 仅内置 GitHub 可运行固定 stdio 二进制，自定义插件仍限 HTTPS Streamable HTTP。服务以 read-only、指定工具白名单运行；AI 只能访问用户勾选仓库。登录状态与访问令牌留在进程内存，不写库、不进入 AI 上下文/审计；应用重启需重新连接，未连接时 AI 不会启动服务或发起首次登录。官方服务会自动刷新令牌；若令牌到期且刷新失败，可能重新要求浏览器授权，授权信息不回灌 AI。
- OAuth 登录辅助的账号查询/仓库选择不可作为 AI 工具。选择仓库才启用；断开中止该用户登录及在途调用。授权超时/取消不启用插件。
- 网页共读默认跳转选定的 Chrome / Edge，在本机连接页点击「连接此对话」即可配对，无需填地址/码。首次需要用户安装一次扩展；随后在目标网页点击扩展「共读当前页」开始，未主动开始前不采集。内置独立浏览窗口仅作备用。
- 共读远程页面不允许 WebMessage/HostObject 访问；只读正文/当前划选，启动前不提取，停止/关闭清除临时页面，页面内容不得成为宿主指令。网站登录与最终 GitHub 授权由用户完成。

## 对话入口
- “更多功能”仅保留出题、联网搜索、GrillMe，以及桌面可用时的网页共读/截图。移除情景题、导出对话、图片、存入记忆、文档模式的重复菜单项；粘贴/拖拽图片和已有内容仍正常工作。
- 网页共读/截图不再占上方主功能栏；截图仍需预览并由用户发送。

## 练习
- 本组题可部分作答或全部空白交卷。仍提交所有题目的完整快照并检查版本；思考不代替答案。未作答按未答/零分记录，解析可提供学习建议但不能假装答对。
- 情景题空白提交不解析空 JSON；非空操作记录仍严格校验。

## 应试资源
- “补充/搜集应试资源站”等明确请求可驱动读当前范围 → 联网发现/验证 → 展示新增域名计划 → 用户确认 → 保存。模型不应被直接强制跳过搜索写入，也不得将拒绝后的计划重复提交。
- 发现时不受原应试白名单限制（否则无法发现新域名），仅白名单已确认的更新用于后续题源过滤；不宣称未经搜索的站点已验证。

## 图解
