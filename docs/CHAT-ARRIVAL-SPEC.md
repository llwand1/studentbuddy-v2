# 魔法营地与对话衔接（v0.2.177）

## 光影与魔法

保持既有 96×144 建筑和粗像素精度。遗迹用青绿与冰蓝，图书馆用琥珀与紫晶；竖向光柱、门光、地面反光、双层符文结界、悬浮魔法碎片与雾形成前后层次。建筑仍固定，动态发生在光影和魔法层。悬停及键盘聚焦让对应结界点亮，点击仍传送到真实功能页。

导航展开时建筑和魔法环境退场，收起时再点亮；手机保留紧凑功能入口。魔法层限制在两侧留白，中央阅读区、题干和底边输入不受环境遮挡。答题仍按真实判定区分命中、失误、待核对和部分正确，但加入双色法阵、棱光和多色火花；颜色变化不代替明确的文字和形状。

## 首问衔接

只在用户从当前空营地实际发出首问时启动。输入、热身追问与引路灯共用发送路径；动画不等待模型，不延迟首字，不新增出题或评分请求。

- 开新会话期间保留当前营地和当前题目的退出画面，停止继续召题；不会在新会话就绪前闪回加载画面或再召一道题。保留仅用于这一问的衔接，新的空会话仍现场生成新题。
- 真实用户消息与生成状态进入后，旧营地以光痕收束，标题和消息同时进入。退出画面从文档流中移除，不把消息推到屏幕下面；输入和停止生成始终可操作，退出的题卡不接收指针与键盘。
- 衔接约 680ms 后清理，消息已在动画期间实时渲染。后续回复和历史对话不重新播放。切会话、发送失败、组件卸载或中途开启减少动态效果清理退出状态，迟到计时器不能拉回旧营地。
- 未从营地发出的历史恢复、断线重连和普通页面导航不触发首问衔接。失败信息、已收到的回复和原有滚动锚定保留。
