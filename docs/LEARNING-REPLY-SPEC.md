# 普通对话的学习回复

> v1.0 · 2026-10-08 · 活跃。依据桌面 `studentbuddy-learning-agent-design-doc.md` 的研究建议，按现役能力实现。

## 1. 回复形态

解释概念、纠错时，普通讲解先用一句话给核心结论，紧接一行 2–3 个关键词，再按需要展开；计算题开篇用一句求解路线定位方向。分步讲解在每一步连起来说清「做了什么 → 为什么这样做 → 得到了什么、如何接下一步」。这三件事是解释要素，不要求三个小标题或三段；段落/列点和详略仍服从用户的四维回答偏好及本轮明确请求。

计算题不先报未经推导的最终数值，结果和代入验算放在一起；用户明确只要答案时先核对再给。这是模型提示约束，不能替代题卡现有盲解核对。真实模型两次在这道简单方程开篇报错、后文算对，故不机械套用桌面文档的答案先行规则。熟悉概念要直接讲清具体边界/易混淆点，不能只邀请下轮再讲；学习记录的次数与正确率不复述到正文，不宣称已经掌握。

闲聊、工具操作回执、仅出题不套讲解模板。用户选择引导式口吻或 GrillMe 时，先问关键问题，避免先泄露练习答案。已有 SVG/图片/交互演示靠近其解释段；沿用现有学习卡片与 Markdown 和像素冒险界面，保持「流什么就存什么」。

步骤间插入解释后，后续有序列表保留原文的起始编号（包括嵌套层）；不再因分块把每步显示成 1。流式与历史使用同一解析/渲染链。

明确的知识提问按已选回答偏好直接开始，不仅因为「可以讲深或讲浅」先弹路线选择卡；需要选路线、做计划或用户明确犹豫时，沿用现有选择流程，GrillMe 显式开启时仍按模式先问方向。

一次完整讲解后，可以建议用自己的话复述一个关键原因，或进入现有 GrillMe（当前对话范围）练一轮。只选一个下一步，不每轮邀请、不叠加对战与练习邀约。正式题卡继续经 `generate_quiz`，普通对话无强制作答闸门。

## 2. 基于证据调整详略

桌面文档所述深度理解/evo_level 链已在 2026-09-25 下线，三列只是历史库面，无生产判定记录（`DEEP-UNDERSTANDING-SPEC.md` 墓碑）。不能把它当掌握度，也不能推荐已不存在的入口。现役复习已有 FSRS；本批不改调度。

新增 `chat/learning-context.ts`：只对本轮检索的最相关 5 个本人词条读记录，写入独立 `learning` system 段：

- 近 30 天各词条最近 5 道不同题的明确对/错结果；同一题重做只保留最新一次，待核对/坏 JSON/无题标识不算证据。
- 词条复习状态复用 `SELECT_REVIEW_COLS` / `toReviewTerm`，包括个人 FSRS 缩放；记忆可提取度不是理解等级。
- 未解决且挂在该词条上的误区，最多 2 条。

有未解决误区、最近一题错、或已复习且当前可提取度低于 80%：补讲相关前提和错因。至少 3 道不同题、正确率 ≥80%、最新答对且无上述缺口：可减少重复定义，重点讲适用边界/反例，必要时让学习者补一步。其余证据不足：给完整关键步骤，不断言「已掌握」。本批阈值是保守产品规则，不是论文验证的诊断量表。

没有相关词条/没有真实练习或误区记录 ⇒ 不注入此段；读取失败 ⇒ 回空，不增加模型调用或阻断对话。只按本人 owner 读词条、答题和误区；邻居概念与全局能力估计不用于推断本主题掌握。每个词条的名称/误区以 JSON 字符串呈现，并声明只是记录不是指令。

`context-segments.ts` 有序清单同时驱动装配和 token 预算，新增段计入同一个 `systemPromptTokens`；不另写预算。`chat.turn` 提示词版本 3→4，便于按版本比较质量与耗时。

表达规则由 `chat/learning-reply.ts` 根据详略/口吻构造，接在本轮原偏好段之后；不塞在长工具提示前端。明确的求解/计算/推导请求或带数字的等式，只下发路线规则，避免同段概念结论指令相互干扰；轻量识别不增加分类模型调用。简短档明确不分步，引导式段不下发结论先行规则，计算题路线优先于原偏好的「结论先行」。出题侧共享四维偏好保持原文。

2026-10-08 v0.2.168：线上默认联网路径实测搜索/绘图后最终正文回到旧格式。每次工具结果回灌后，将同一个本轮偏好消息移到工具结果之后，不复制，不修改结果或历史，不增加预算和调用。一次性联网/选择指令仍仅首轮保留。`chat.turn` 提示词版本 4→5，便于对比工具后的最终回答。

普通讲解公式优先使用可直接阅读的符号/行内代码，分数用 `(分子)/(分母)`，避免显示 `$` 分隔符与命令源码。v0.2.169 的常见公式展示见下；用户明确索要 LaTeX 源码时可用代码围栏。题卡协议保持现状，不引入公式依赖。

需要工具时先调用，途中文字至多一句过程说明，完整讲解在工具返回后一次交付；避免先流出完整旧格式答案、再在工具后重复一份。保持已输出文本与落库一致，不做事后替换。

## 3. 研究依据与修正

### v0.2.169：学习卡片与白底图面

知识讲解可以输出 Markdown 引用卡：首行 `> [!CORE] 标题`，正文每行以 `>` 开头，空段用单独的 `>`。支持 CORE（核心结论）、ROUTE（求解路线）、STEP（推理步骤）、EXAMPLE（例子）、PITFALL（易错点）、CHECK（验算）；标题可省略。普通讲解优先 CORE，计算优先 ROUTE；仅有需要时选择其它卡片，不强制每轮填满，简短档至多一张，引导式不先给答案。关键词可放在首卡正文，图用独立 svg/mermaid 围栏紧邻解释。格式不完整或未知类型按普通引用显示；不要求 JSON，不做额外模型修复调用，流式和历史使用同一解析器，原文落库不变。卡面沿用像素边框、余烬金/血红与正常正文，轻微阶梯入场并尊重系统减少动态效果偏好。

SVG 不再把纯黑/纯白改成夜间主题色。预览、放大和下载使用同一净化后的白底图，旧主题变量解析为纸面深色文字和线条，透明图加白色底层，保留已有显式配色和绘图内容。模型生成的新图使用白底、深色文字/连线、至少 16px 标签；手机缩放后可点放大，避免密集小字。图表和题图共享该处理；外链、脚本与 CSS 作用域约束继续生效。

实测旧模型将 SVG 请求误走生图工具并编造失败图片地址；本轮表达段明确思维图/流程图直接编写 svg 围栏，不用生图或图片搜索代替，真实图片才用图片工具。图片失败不得编造本地地址。

手机宽图（原宽 >420）维持至少 600px 图面并局部横向滚动，显示滑动与放大提示，不把所有标注缩成小字，不撑破页面。普通讲解的收尾练习邀请只用文字，不用 ask_choice 挂起；显式路线选择和 GrillMe 提问保留原流程。

实际截图发现模型将节点画出 viewBox 边缘。净化后在不可见的隔离容器测量原生 SVG 图形边界，只向外扩展已有视口并留边距，同步宽高比例；不重排节点或缩窄原视口。测量失败或异常大边界保留原图；临时容器必回收。随后按新视口铺白底，同一结果用于预览、放大、下载。

工具轮回灌的 assistant 消息保留该轮真实输出的 turnText，并计入工具回灌预算；不能用空字符串抹掉模型已经讲过的内容，否则后续轮不知道学生看过哪些解释，重复讲解。同一份正文继续正常流式上屏与最终落库，不事后改写。

若本轮工具调用前已经输出 CORE/ROUTE 卡，在同一偏好消息尾部追加一次已交付提示，后续续写而不重开结论/路线卡；增加的文本计入工具预算。只检测当前轮输出，不把历史卡片当成本轮已讲过。简短限制作用于整轮，短讲解不额外查询维护词条；明确操作与必要检索按原流程。

v0.2.179 公式阅读升级为 KaTeX，覆盖行内、独立公式、显式 math/latex/tex 围栏及引用卡中的公式。计算按参考答案式逐行推导、等号对齐，结果与验算相邻；未知命令或坏括号整式保留源码，流式未闭合占位，历史与完整流式同源。普通代码围栏不解析公式。图解接入 Mermaid，完整后自动布局，仍走 SVG 净化与白底纸面。详细契约与开源选型见 [MATH-READING-SPEC.md](MATH-READING-SPEC.md)。chat.turn 提示词版本 7→8。

参考：[Brilliant 的图文互动学习](https://brilliant.org/)、[Anthropic Artifacts](https://www.anthropic.com/news/artifacts)、[GitHub Markdown Alerts](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#alerts)。本项目只借鉴语义卡片与图文相邻的表现，不复制品牌或新增任意 HTML 注入。`chat.turn` 提示词版本 5→6。

- [AITutor 实地研究](https://arxiv.org/abs/2607.01692)：12 人部署、7,379 条事件，支持先看结论作为诊断检查点、分层例题与图文关联的设计方向；不是所有用户学习效果提升的随机实验。
- [ICAP 原论文](https://doi.org/10.1080/00461520.2014.965823)：学习者自解释、主动构造有价值；据此提供自愿复述/练习，而非一律扣住答案。
- [Dunlosky 等 2013](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)：自测、分散练习为高效用。桌面文档的 Frontiers 2021 URL 不是该论文，应使用原出版信息；不改变现有复习算法。
- [DeepTutor](https://arxiv.org/abs/2604.26962)：借鉴动态学习记录反哺讲解，技术报告仍在进行中；不复制多代理/Trace Forest 架构，不新增后台模型调用。

## 4. 验收

v0.2.170：六种已知标记即使只有独立标题、正文另起段落，也渲染原生卡片标题，不露出内部标记，不吞掉后续段落或表格。未知标记仍按普通引用显示，代码围栏保持原文；不推断段落归属、不新增模型调用，流式和历史共用同一解析器。

自动锁：无证据不误判、足够不同题才收缩、同题重复与旧记录不抬高判断、最近答错/误区/遗忘优先、跨用户隔离、缺库不阻断、最多 5 条且素材非指令；出站段与预算同源、多段 system 在 Anthropic 侧完整下发、流式文本与库内文本一致。

真模型：默认概念问、详细推导、带练习记录的熟悉概念、最近答错/误区、简短和引导式偏好；检查无已下线入口、无格式源码泄漏，并回读历史。桌面/手机查看既有 Markdown 与像素样式。全量 check、build、metrics、guard-audit、demo:e2e 后发布。
