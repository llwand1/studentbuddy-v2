# 知识大陆接入

状态：基础版（词条地图＋四题型复习＋图鉴）已随 v0.2.136 上线；优化批（走位／领地／宝箱联动／情景题）落在分支 `feat/knowledge-continent`，未合 main、未发版。

## 本轮行为

- 侧栏独立「知识大陆」入口，地图显示当前用户的词条。
- 按词条创建顺序从中心铺格，首轮最多显示 140 格。
- 复习范围内到期或逾期的词条生成怪物；范围外词条显示普通地块。
- 点击怪物进行本地词条复习，全部答对后调用既有复习接口，成功后刷新地图并播放收复效果。
- 判断、选择、填空、连线和情景五种题型；等级对应题数与血量，图鉴为题型有序组合。
- 保存失败保留当前挑战，显示反馈并允许重试；不重复推进复习阶段。
- 图鉴为已有复习记录的派生视图，不新增存储。
- **英雄走位**：键盘方向键／WASD、页面方向键、点地自动寻路三路入口；走位是纯界面状态，不落库。
- **靠近才开打**：点怪本体需与之相邻（曼哈顿距离 ≤ 1），够不着会自动走过去并提示，不放行隔空打怪。
- **领地扩散**：怪占几格由逾期天数派生（`landCountFor`＝`clamp(1+floor(days/2),1,6)`），吞哪些格由确定性贪心 `spreadLands` 决定（词条格优先、荒地次之、跳过英雄格）；没有定时器、没有存档、没有新表。
- **点击占领区＝复习领主**：点领地不要求相邻，答对即「解除占领」；这是领地唯一可持久化的解除路径。
- **地图宝箱**：地图上落宝箱，点开复用既有每日宝箱接口与开箱仪式，稀有度沿用既有分档；地图只是既有账本的第二个入口。
- **过渡特效**：领地呼吸、宝箱浮动、开箱光环与击杀 burst，只动 `transform`／`opacity`，系统「减少动态效果」偏好下逐条退化为直接显示结果。

## 数据与来源

实现来源：Trae-A1 的 `92dc58c`，基于 main `b88dab5`。集成保留原提交，并在像素统一分支补充验证、像素怪物与保存失败恢复。

地图接口 `GET /api/terms/review/map` 为只读接口，按现有账号归属查询；复习写入复用现有接口。无新增数据库表、迁移或随机稀有度规则。优化批（走位／领地／宝箱联动／情景题）在分支 `feat/knowledge-continent`，同样**零新表、零迁移、零新写口**：宝箱走既有 `POST /api/cards/chest/open`，领地与走位是派生量／界面状态。

## 本轮边界

基础版与优化批合计接入的仍是「词条地图＋复习挑战＋走位／领地／宝箱／五题型」。**尚未实现**：历史副本生成、AI agent 地图生成、Boss/PK 联动。**尚未验收**：真机（浏览器）——Canvas 走位、领地呼吸与开箱特效只在 jsdom 下用 canvas 打桩验证过，浏览器内实观效果未看。

★ 一处**代价如实登记**：情景题进可用题型使图鉴槽 **84 → 155**，并重算已有怪的题型序列（模数 4→5）。这是口径本身决定的，不是 bug；图鉴是派生视图，复习阶段与流水一字未动，无用户数据丢失。

本轮已统一像素界面、卡牌与题库删除结果；题库、笔记、今日总结、学习流和旧知识图入口保持下线。知识大陆是新的词条地图，不恢复旧知识图功能。新增玩法另写对应契约。
