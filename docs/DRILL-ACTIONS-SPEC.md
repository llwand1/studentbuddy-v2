# 刷词动作反馈（v0.2.178）

“收入词库”与“斩”按动作含义使用不同的原创粗像素反馈，借鉴百词斩明确的背词动作和进度反馈，保留暗黑冒险界面。普通答题继续轮换原有五款特效，不给每种动作叠同一个通用法阵。

- 收入词库：请求期间原卡留在原处，按钮显示“正在收入…”，禁止重复收入及同时“不要”。只有服务端成功后播放青蓝书页聚拢、书本合页与落库印记，显示词条名及“已收入词库”；约 720ms 后续卡或返回对话。失败显示错误，保留当前卡并恢复重试，不播放成功反馈。结束本局或卡已切换后的迟到响应不能推动新卡。
- 斩：单道刃光切开词条名，两半错位与碎屑消散，显示“今天不再出”。它是当天本机排除，仍不表示答对、永久掌握或复习打卡。重复按键不得重复计数；约 520ms 后续卡或返回对话。
- 两者的反馈、颜色、运动方向、形状与音效分开。特效限制在词卡内，不增加模型或写入请求；原有音效开关、收起/唤回、键盘与手机布局继续生效。减少动态效果隐藏运动图形，文字状态照常可读，结束本局清理计时器。
