# 知识大陆首轮接入

状态：开发版集成，尚未部署。

## 本轮行为

- 侧栏独立「知识大陆」入口，地图显示当前用户的词条。
- 按词条创建顺序从中心铺格，首轮最多显示 140 格。
- 复习范围内到期或逾期的词条生成怪物；范围外词条显示普通地块。
- 点击怪物进行本地词条复习，全部答对后调用既有复习接口，成功后刷新地图并播放收复效果。
- 判断、选择、填空和连线四种题型；等级对应题数与血量，图鉴为题型有序组合。
- 保存失败保留当前挑战，显示反馈并允许重试；不重复推进复习阶段。
- 图鉴为已有复习记录的派生视图，不新增存储。

## 数据与来源

实现来源：Trae-A1 的 `92dc58c`，基于 main `b88dab5`。集成保留原提交，并在像素统一分支补充验证、像素怪物与保存失败恢复。

地图接口 `GET /api/terms/review/map` 为只读接口，按现有账号归属查询；复习写入复用现有接口。无新增数据库表、迁移或随机稀有度规则。

## 本轮边界

首轮接入的是实际词条地图与复习挑战。桌面原型中的角色走位、领地扩散、宝箱和完整五题型尚未全部接入；词条卡墙与卡牌奖励已合入同一版本，但地图掉落尚未联动。情景题、历史副本生成与 Boss/PK 联动保留后续工作。地图宝箱须复用卡牌奖励账本。

本轮已统一像素界面、卡牌与题库删除结果；题库、笔记、今日总结、学习流和旧知识图入口保持下线。知识大陆是新的词条地图，不恢复旧知识图功能。新增玩法另写对应契约。
