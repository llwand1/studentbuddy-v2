StudentBuddy 桌面 0.2.201 · Windows 10/11 x64。

新增 B站公开学习插件：无需 Token，显式启用后跳转指定浏览器。主 Agent 能按有证据的学习方向检索真实视频和资料，选择视频，依据实际简介 / 共读划选 / 用户笔记交付单题，并检索相关视频。账号历史与完整音视频自动转录不在本版范围；Agent 不能编造字幕，笔记通过用户学习卡单独提交。桌面定时出题范围新增 B站学习视频。

主动练习改为吉祥物旁的独立邀请气泡，点击挑战才展开题卡，可延后两分钟；不抢焦点、不改变 64px 本体裁剪、不堆题。新增中文逐字显现、像素字符符文及兴奋 / 鼓励表情；减少动态效果使用静态完整文案。邀请在多屏 / DPI 工作区边缘翻转，并避开悬停快问条。

本版补齐 HTTP 可靠性：异步路由统一转交 Promise 拒绝，最终错误边界返回安全的 JSON 与请求标识。严格拒绝模式的真实服务进程验证失败请求和断流后仍可继续服务。云端新增通用及高成本 API 请求预算；本机模式不受此预算影响，既有登录与模型并发限制保留。共享领域模块完成拆分并纳入 400 行门禁，原有公开入口与数据兼容。新增仅向新目标恢复 SQLite 快照的工具，包含 WAL、完整性、竞争覆盖与错误恢复验证。README 改为产品场景与实际操作演示，移除创新自评标题。构建来源状态核对规范化内容，修复换行状态被误报为源码修改。

首次共读可现场下载扩展 ZIP，不必找安装目录：连接页与应用一级入口均提供下载，按解压、加载文件夹、刷新逐步指引。未检测到扩展时禁用连接按钮；扩展 ZIP 与 SHA-256 随本 Release 单独提供。

默认网页共读跳转用户选定的 Chrome / Edge，通过本机连接页配对；首次安装一次扩展，之后无需手填地址/码。GitHub 复用同一浏览器选择，不改变系统默认。主 Agent 可实时重搜/追加/筛选/排序找视频，不能编造来源。悬浮对话恢复与展开默认最新轮，手动上翻不被生成打断。仓库改为 xuelian-agent，应用名、旧数据路径、更新签名不变。

本版新增 GitHub 浏览器快捷授权：设置 → 插件 → 连接 GitHub，在选定浏览器授权后勾选仓库直接启用，无需配置 Token；高级 Token 接入仍保留。浏览器登录令牌仅在内存，应用退出后需重新连接。主对话可真实读取仓库文件、Issue、PR 与 Actions。支持导入 JSON 声明接入其他公网 HTTPS Streamable HTTP MCP 服务，第三方工具每次调用需确认。Token 加密保存，调用状态可见；停用会中止请求。子 Agent 插件授权、GitHub 写操作尚未开放。

本版精简更多功能菜单，移除情景题、导出、图片、存入记忆和文档模式的重复入口，将网页共读与截图移入；题组允许未答完交卷，未答按零分处理。AI 可搜索并验证应试资源，再通过确认卡新增域名；修复合法 Mermaid 颜色样式被误拒绝，失败可重试并保留源码。

本次增加悬停快问与本机截图：鼠标移到吉祥物显示「输入提问 / 截图提问」，主窗口也有截图入口。框选后先本机预览，放入原对话的输入框，点击发送才交给视觉模型；支持 Esc 取消、Enter 整屏，不持续采屏。修复本机能力问题被默认联网搜索带偏：先核对真实本机工具和桌面路径，远端模型不等于没有本机文件能力。

本次新增独立任务中心：引路灯旁「☷」可查看真实任务、子 Agent、逐题分析与后台队列，管理取消、失败重试和结果。一级子 Agent 使用独立上下文，每用户最多并行 3 个。电脑文件按需只读，工作区可读写文本；敏感路径/正文特征和手动标记触发具体操作的一次许可。任务与设置持久化，重启不自动重放写入。当前文件工具为文本，不运行程序或删除文件。

同时保留上一版桌面优化：小屏上方控件收紧，移除重复品牌栏，探索菜单改为引路灯旁的方形按钮；输入框不再溢出窗口。收起保留对话、草稿和滚动位置，重启恢复上次悬浮窗会话。补齐服务重启、WebView 重建与桌面进程崩溃守护，正常退出不重启。

- 下载本页 Assets 中的 `windows-x64-setup.exe` 安装程序，双击安装，从开始菜单启动。
- 内置 Node 运行时，自动打开应用窗口；首次使用在设置中配置自己的 AI 服务商和模型。
- 托盘菜单可以打开应用或退出，重复启动共用一个服务。
- 桌面悬浮球：启动后桌面上出现一只吉祥物（就是应用里那只像素团子，按它的外形裁出窗口，没有底板）。点一下展开成手机大小的窗口，可直接问问题、刷词刷题；按住拖动可换位置并记住。托盘菜单可显示/隐藏它。
- 定时练习：右键吉祥物或使用托盘菜单主动开启，默认每三分钟显示一张独立题卡，直接作答和看解析；可调整间隔、跳过或延后，未答不堆题。
- 网页共读：更多功能 → 网页共读，默认跳转选定的 Chrome / Edge。首次在连接页下载 ZIP、解压并加载扩展，刷新后点击连接；之后从扩展启动共读当前页。正文、划选和视野临时同步当前对话，停止/关闭即清除；不便安装扩展时可选择内置窗口备用。
- 应用图标统一为吉祥物（安装包、快捷方式、托盘、任务栏），安装时默认创建桌面快捷方式。
- 学习数据存放在自己的电脑上，升级和卸载保留数据。
- 桌面更新：应用后台检测并准备新版，下载校验完成后提示重启；托盘菜单也可主动检查。升级前备份程序和学习数据库，新版本启动校验失败时恢复旧版。
- 0.2.0 及更早安装版需要手动安装本版一次，随后可使用自动更新。

安装、启动、保存会话、重复启动、停止、升级和卸载均通过隔离环境验证。安装程序尚未做代码签名。

桌面版使用独立的 `desktop-v<版本>` 发布通道。校验值见 `SHA256SUMS.txt`，自动更新清单使用签名校验；安装程序本身尚未做 Windows 代码签名。
