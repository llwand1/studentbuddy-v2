StudentBuddy Windows 本地版

从开始菜单启动 StudentBuddy，会打开应用窗口。
第一次使用请在设置里配置自己的 AI 服务商与模型。
关闭窗口后，服务仍在托盘运行；右键托盘图标可打开应用或退出。

启动时桌面上还会出现一只吉祥物（悬浮球）。点一下它会展开成手机大小的窗口，可以直接问问题、刷词刷题；按住拖动可以换位置（位置会记住）。托盘菜单可显示/隐藏它，或用「悬浮球回到吉祥物」把它收回原样。

右键吉祥物或托盘「定时出题与网页共读」可开启自动练习：默认每 3 分钟弹一张独立题卡，不用打开小屏应用；间隔可改为 1–60 分钟。题卡不主动抢焦点，做完/跳过后重新计时，也可延后两分钟。展开应用或隐藏吉祥物时不会自动弹题，未做完不会堆题。需先配置本机 AI，或准备当前学习范围的可编译题目蓝图。

网页共读：安装目录 browser-extension 文件夹中附带 Chrome / Edge 扩展。扩展管理页开启开发者模式，加载该文件夹；在桌面设置或主窗口「网页共读」生成配对码，在扩展填入本机地址和配对码，然后选择「共读当前页」。只同步主动选中的网页；页面、划选和当前视野变化会更新临时索引。回到绑定对话提问，或选网页作为定时出题范围。网页文字只在本机内存，停止/关闭标签页或断连后清除，不自动存入资料库；相关片段会送给你配置的 AI 模型。应用或浏览器重启后需重新配对。详见 browser-extension/README.md。

支持 Windows 10/11 x64，无需另装 Node 或 npm。应用窗口依赖系统自带的 WebView2 运行时（Windows 11、以及装过 Edge 的 Windows 10 自带）；若运行时缺失，会改用默认浏览器打开并在日志说明原因。
学习数据使用既有 studentbuddy-v2 数据目录，升级和卸载不会删除学习数据。
应用启动后会后台检查桌面更新并下载新版，校验完成后提示重启。也可在托盘菜单选择「检查更新」或「重启更新」。安装前备份程序和学习数据库；新版本未能正常启动时恢复旧版。
0.2.0 及更早版本需要先手动安装一次带更新器的版本，之后即可使用自动更新。
启动日志：%LOCALAPPDATA%\StudentBuddy\desktop.log

项目与源码：https://github.com/llwand1/studentbuddy-v2
