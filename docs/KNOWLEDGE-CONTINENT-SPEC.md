## 本轮行为

- 侧栏独立「知识大陆」入口，地图显示当前用户的词条。
- 按词条创建顺序从中心 `(0,0)` 铺格；**世界比屏幕大**（半径由词条数派生，只增不减），屏幕只是视野，可拖拽平移。
- 复习范围内到期或逾期的词条生成怪物（**欠账怪**）；范围外词条显示普通地块。**2026-09-29 起另有每日随机的野怪**（见 §「刷怪：欠账怪 + 野怪并存」），新用户第一天也有怪可打。
- **开拓地块（2026-09-29）**：大陆边界上的每个空格画「+」；点它领一条**新词条**（AI 按邻格领域现生成，没模型退内置词池并如实标 `source:'fallback'`），答对两道随机题型的题，新地块就长在**点的那一格**（见 §「开拓」）。
- 点击怪物进行本地词条复习，全部答对后调用既有复习接口，成功后刷新地图并播放收复效果。
- 判断、选择、填空、连线和情景五种题型；等级对应题数与血量，图鉴为题型有序组合。**怪的外观随题型组合走**（2026-09-29：155 种外观与图鉴槽一一对应，见 §「怪种外观」）。
- 保存失败保留当前挑战，显示反馈并允许重试；不重复推进复习阶段。
- 图鉴为已有复习记录的派生视图，不新增存储。
- **英雄走位**：键盘方向键／WASD、页面方向键、点地自动寻路三路入口；走位是纯界面状态，不落库。
- **靠近才开打**：点怪本体需与之相邻（曼哈顿距离 ≤ 1），够不着会自动走过去并提示，不放行隔空打怪。
- **领地扩散**：怪占几格由逾期天数派生（`landCountFor`＝`clamp(1+floor(days/2),1,6)`），吞哪些格由确定性贪心 `spreadLands` 决定（词条格优先、荒地次之、跳过英雄格）；没有定时器、没有存档、没有新表。
- **点击占领区＝复习领主**：点领地不要求相邻，答对即「解除占领」；这是领地唯一可持久化的解除路径。
- **地图宝箱**：地图上落宝箱，点开复用既有每日宝箱接口与开箱仪式，稀有度沿用既有分档；地图只是既有账本的第二个入口。
- **过渡特效**：领地呼吸、宝箱浮动、开箱光环与击杀 burst，只动 `transform`／`opacity`，系统「减少动态效果」偏好下逐条退化为直接显示结果。
- **魔法吟唱（`docs/SPELL-CHANT-SPEC.md`，issue #85）**：打怪弹窗里的一次性技能——从历史对话里选一段当「咒语」，复述当初的提问＋重做当初的题，命中几节打几点、正文提到这块地的词条则 ×2；伤害直接掉血（＝替你答掉几道题，「题数＝血量」不破），释放特效是 canvas 像素编排、每次吟唱掷骰五款之一（`shared/spell-kinds.ts` 款式表；`spell-fx*.ts` 引擎），咒语补上最后一击时地图 burst 换成同款的地图版（`spell-burst.ts`，≤ 1s）。零迁移、零新路由，口径全在 `shared/spell-chant.ts` / `spell-kinds.ts`。★ 已在 headless Chromium 对真页面把五款各走通一遍并截图（见该册 §7/§8）；特效在软件栅格器上有像素断言（`spell-fx.test.ts`）；真实设备与 reduced-motion 画面未做。

## 开放世界与视口（2026-09-27 开放世界那次改动）

★ **口径变更**：地图从「**一屏＝全世界**（14×10＝140 格，装满即截断）」改成「**世界比屏幕大，屏幕只是视野**」。成因＝09-27 提出「**地图可以是开放式的啊，屏幕中的只是视野范围而已**」——当时他库里 327 条词条有 **187 条根本没上地图**（旧横幅「地图满 140 格，另有 187 条词条暂未铺上图」就是它）。三项裁定：① 档位＝**折中**（世界只增不减＋视口相机）② 伙伴上限**跟着世界涨** ③ 相机＝**拖拽平移 ＋ 一键回到英雄**。

### 坐标与尺寸（两件不再混为一谈的事）

| 概念 | 口径 | 谁在用 |
| ---- | ---- | ------ |
| **视口**（viewport） | `CONTINENT_VIEW_COLS × CONTINENT_VIEW_ROWS = 14 × 10`（672×480 像素） | canvas 像素尺寸、命中换算 |
| **世界**（world） | **有符号坐标 `(row, col)`，中心 `(0,0)`**，半径 `R` ⇒ 共 `(2R+1)²` 格 | 铺格、领地扩散、走位、点击 |

- ★ `CONTINENT_COLS`／`CONTINENT_ROWS`／`CONTINENT_CELLS` 三个旧名字**删除**，换成 `CONTINENT_VIEW_*`：名字里的语义已经变了（世界 ≠ 视口），留着就是"名字骗人"（它们此前一直被当成"世界尺寸"用）。
- ★ **相对布局与今天逐一对应**：今天的中心是 `(floor(10/2), floor(14/2)) = (5,7)`；新坐标 ＝ 旧坐标 −(5,7) ⇒ 前 140 格在屏幕上的**相对位置一格不差**，只是索引基准变了 ⇒ 已有词条与伙伴的落位（`npc:<termId>`）**一个都不换**。
- ★ **零存储 ⇒ 零迁移**：没有任何表存 `row`／`col`（全是派生量），换基准不动一行数据。

### 世界半径：只增不减

```
WORLD_MIN_RADIUS = 7        // 15×15 = 225 格 ⇒ 初始世界就比视口大（一眼看得出"视野只是一部分"）
WORLD_MAX_RADIUS = 40       // 81×81 = 6561 格（到顶才可能再截断，那是另一个量级的词条数）
worldRadiusFor(n) = clamp(ceil((sqrt(n) - 1) / 2), 7, 40)
```

- ★ 只增不减（`sqrt` 单调）⇒ **加词不会挪旧格**。本机实测数字：`n=327 ⇒ R=9`（**19×19＝361 格**，装得下）、`n=140 ⇒ R=7`（225 格）、`n=0 ⇒ R=7`。
- ★★ **铺格前缀必须稳定**：`spiralCells` 改成「**固定中心 (0,0)** ＋ 按圈外扩 ＋ 越半径丢弃」。原实现的生成序列与 `cols`／`rows` **无关**（只在越界时丢弃）⇒ 固定中心后前 k 格恒同 ⇒ 加词只会在**外面续圈**。
  ⚠️ 这正是**不能**沿用旧写法的原因：旧中心是 `floor(rows/2), floor(cols/2)`，尺寸一变中心就漂（10 行→第 5 行、14 行→第 7 行）⇒ 全世界重排。有符号坐标把这件事从"靠尺寸对齐"变成"**根本不依赖尺寸**"。
- `layoutTiles(terms)` 的半径**由它自己现算**（`worldRadiusFor(terms.length)`）：单一入口，调用方给不出错的半径。

### 领地 / 可通行 / 点击

- `spreadLands` 的边界参数由 `cols`／`rows` 改成 `radius`（世界为 `[-R, R]²`）；每只怪仍封顶 `CONTINENT_MAX_LANDS = 6` 格 ⇒ 世界变大**不会**让领地爆炸。
- 英雄**仍只在词条格上走**（本次**不做**荒地可走：动它要碰既有取舍、回归面大，另立改动）。
- 点击命中：由「整幅比例换算」改成「**视口比例换算 ＋ 相机偏移**」——这是本节唯一必须与渲染同时改的地方，漏了就会出现"点到的格 ≠ 画出来的格"。

### 相机（视野怎么动）

- 状态：`cam { row, col }` ＝ 视口左上角的世界坐标。
- **拖拽平移**（鼠标/触屏）看远方；**「回到我身上」**一键把英雄居中；键盘走位仍只作用英雄。
- ★ **英雄走出视口 ⇒ 相机自动跟到"最小可见"**（不跟随就会让英雄从画面上消失，那是死路；ADR-5 禁静默）。
- ★ **只画视口内的格**（±1 格余量）：世界 361 格起，逐格全量绘 ＋ 全量"长出来"动画会白跑（同 `ContinentMap` 文件头"静止不开 rAF 循环"的取舍）。
- ★ 旧横幅「地图满 140 格，另有 N 条词条暂未铺上图」**删除**（不再截断），`ContinentView.truncated` 字段一并删掉——不是"改成 0"，是不留一个永远为 0 的字段。

### 伙伴名额跟着世界涨（`NPC-PARTNER-SPEC` §2.1 同步改）

```
npcCapFor(R)           = clamp(floor((2R+1)² / 40), 6, 24)   // ≈ 每 40 格站 1 位（**名额上限**）
npcTasksRequiredFor(N) = 3 × (N-1)                           // 创建第 N 位的门票：第 1 位无条件
```

- 依据＝需求第 ⑦ 条「根据地图大小就会有 npc 的数量限制，这也就鼓励用户通过学习来开疆拓土」：**上限必须跟着世界涨**，否则 327 条就顶死在 6 位，"开疆拓土"没有奖励感。
- ★★ **伙伴创建那次改动 起"数量"不再由词条数派生**（「npc 不要那么多，由玩家来创建比较好」）：`npcCountFor(n,R)` 与 `placeNpcs` 自动派位**整套退役** ⇒ 这里是**名额上限**，实际几位由**玩家创建 + 门票**决定。
- 本机实测数字：`R=9 ⇒ cap 9`；`R=7 ⇒ cap 6`；`R=20 ⇒ cap 24`（封顶）。
- ⚠️ **这是产品感受值**（密度口径），把握度**中**：先按"每 40 格 1 位、上限 24"落，真机看密度再调；数值集中在这一个函数里，改它不动别处。

## 刷怪：欠账怪 + 野怪并存（2026-09-29，issue：新用户看不到怪）

- **问题**：怪只从「复习范围内 + 到期/逾期」派生，而新词条默认**不在**范围（v28 起）⇒ 新用户的大陆永远一只怪都没有，玩法根本进不去。
- **口径**：两种刷怪方式**并存**，来路记在 `ContinentTileView.monsterKind`：
  - `due` **欠账怪**（原口径一字未动）：范围内到期/逾期；占地（领地扩散）、伙伴遇险的威胁源、打赢＝正常打卡（`POST /:id/review`）。
  - `wild` **野怪**（新增，`shared/continent-wild.ts`）：每天按「日历日 × 词条 id」的稳定哈希对**全部**词条排名，取前 `k = clamp(1 + floor(n/8), 1, 8)` 名；跳过已是欠账怪的、以及**今天复习过**的（`review.basis==='review' && daysSince===0`）。**范围外的词条也会被点名**——这正是新用户有怪可打的来源。
  - 野怪**不占地**（领地只从欠账怪长）、**不算伙伴的威胁源**（`npc-map.ts` 不扫它：它每天换一批，让它牵动伙伴处境会变成"求救单随日历自动完成、白发钥匙"，且新用户第一条词条会没地方安置伙伴）。
  - 打赢野怪 ＝ **提前复习一次**：范围外的先 `PUT /api/terms/review/scope {termId, enabled:true}` 再 `POST /api/terms/:id/review`（范围外直接打卡必 409），弹窗与回话说清"已纳入复习范围"。打赢后它当天不再被点名（今天复习过），**不会有下一名顶上来**（不是无限刷）。
  - 前端只有传了 `dayKey`（本地日历日）才刷野怪；服务端地图接口不变（零存储、零迁移）。
- **界面**：野怪脚下的魔法阵是青绿（欠账怪是血红），本体上下浮动；头部统计多一格「野怪」；`tileStatusText` 说「野怪 · 今天随机盯上了这条」。
- 数量参考：1–7 条词条 ⇒ 每天 1 只；8 条 ⇒ 2 只；56 条以上封顶 8 只。

## 开拓：边界「+」→ 学新词 → 地块长在点的那一格（2026-09-29）

- **边界格**（`shared/continent-expand.ts` `frontierCells`）：世界内、没铺词条、四邻至少一格词条、且不在怪的荒地领地上的格。**全部**边界格都画「+」（不是只画螺旋的下一格）；前端画、服务端校验用**同一份**函数。
- **两步端点**（新路由 `packages/server/src/routes/continent.ts`，挂在 `/api/continent`）：
  1. `POST /api/continent/expand/offer {row,col}` → `ContinentExpandOffer {nonce, row, col, term, definition, domain, source:'ai'|'fallback', fallbackReason?, questions[2], expiresAt}`。非边界格 409、空大陆 409、坐标非整数 400。
  2. `POST /api/continent/expand/claim {nonce, answers}` → `ContinentExpandResult {ok, termId, term, row, col, source}`。服务端**重判**每道题（答错 409 且凭证不作废，可重答）；再验格仍是空地、词不在库里；然后 `saveOneTerm` 入库 + 钉住坐标。同一 nonce 只能落一次（成功即删，再来 404）；凭证 10 分钟过期。
- **新词条从哪来**：AI 优先——`continent.expand` 用途走 `explain` 角色，提示词带邻格的**主导领域**（多数决）与邻近词条名、以及用户已有词条名（不许重复）；**没绑模型或模型失手 ⇒ 内置词池**（`drawablePool`，优先同领域），并如实标 `source:'fallback'` + `fallbackReason`（ADR-5：降级可以，假装没降级不行）。两边都没有 ⇒ 409 说清原因。
- **题目**：题型由 `nonce` 的稳定哈希定（两道不重复、同 nonce 恒同——服务端凭它重判），干扰项来自用户现有词条；池子不够时连线/选择按既有规则退成填空。弹窗先出"先学"卡（词条 + 释义 + 来源），再答题。
- **地块落在点的那一格**：`app_settings` 的 `continent_pins` 键存 `{pins:[{id,row,col}]}`（按 owner 一行，与 `npc_party` 同一条路，**零新表、零迁移**）。`layoutTiles(terms, pins)` 先放钉子、其余照旧螺旋并跳过被钉的格；世界半径 `layoutRadius = max(worldRadiusFor(n+1), 最远钉子+1)`——**永远留着下一块地的位置**。钉子只增不删：词条删了那格自然回到"可开拓"（铺格只认有词条的钉子），撤销删除则地块回到原格。
- 新词条**不算复习过**（`last_reviewed_at` 空）：刚学会的词条由复习引擎按正常节律接管，不白送一次打卡。开拓不要求英雄相邻（它是规划，不是打怪）。

## 怪种外观（2026-09-29：从一张脸到 155 张脸）

- 图鉴按题型序列开了 155 个槽，图上此前永远是同一只「遗忘之影」——"收集"是看不见的数字。现在外观由 `species` 确定性派生（`web/features/continent/monster-art.ts`，零随机）：
  - 第 1 型 → **体型**：判断＝史莱姆、选择＝蝠翼魔、填空＝石魔像、连线＝蛇妖、情景＝幽魂；
