# 阅读工作台（v0.2.172）

阅读、作答与输入是主要动作。导航和辅助提醒保留入口，正文拥有稳定、独立的空间。

- 桌面工具条的“收起导航”隐藏整个左栏，展开时会话搜索、账号表单和历史列表保持挂载。偏好只记在当前浏览器，存储不可用时仍可操作。手机沿用探索菜单抽屉，不受桌面收起偏好影响。
- 资料架默认收起：搜索 sources 帧只更新小入口和引用，不再跨轮自动弹开。点击“资料 N”、脚注或引用才打开；已主动打开的同会话资料架仍接收 live 更新。
- 重载会话后，从已加载的消息恢复最新可用资料入口，不追加请求。切会话清空旧入口；迟到的历史响应不会覆盖其他会话或 live 帧。
- 资料架的“展开阅读”使用整个主区，“对照阅读”恢复左右对照。对话 DOM 保留，切换不会清空草稿或卸载题卡。关闭资料架恢复对话。
- “专注阅读”临时收起桌面导航、引路灯、督促和话题提醒，回收输入框下方为胶囊预留的高度；会话标题移到工具条，默认出题配比说明与装饰余烬收起，自动等待刷词暂停。正文、输入、题卡、工具确认与错误仍可操作。退出恢复之前的导航偏好；主动展开导航也会退出专注。
- 引路灯移入正文外的工具条，不再覆盖标题；主动推荐仍可由灯的状态和点开菜单访问，工具条不展示额外浮动短提示。

无模型、服务端 API、数据库或搜索费用的新增。正文维持既有最大行宽，空出的横向空间用于居中与留白，避免大屏把一行拉得过长。所有新控件沿用整数网格图标、硬边和主题色。

验证复用既有用例，新增仅 5 例，覆盖导航偏好/草稿保留、临时专注恢复、资料主动开合与预览切回、存储失败以及跨会话历史恢复。真实浏览器另测桌面/手机尺寸、滚动位置、资料展开/对照、入口重载、键盘和减动效。
