StudentBuddy 的 Windows 本地安装包，支持 Windows 10/11 x64。

- 下载本页 Assets 中的 `windows-x64-setup.exe` 安装程序，双击安装，从开始菜单启动。
- 内置 Node 运行时，自动打开应用窗口；首次使用在设置中配置自己的 AI 服务商和模型。
- 托盘菜单可以打开应用或退出，重复启动共用一个服务。
- 学习数据存放在自己的电脑上，升级和卸载保留数据。

安装、启动、保存会话、重复启动、停止、升级和卸载均通过隔离环境验证。安装程序尚未做代码签名。

桌面版使用独立版本号；网站的更新仍以 `v0.2.x` 版本为准。校验值见 `SHA256SUMS.txt`。
