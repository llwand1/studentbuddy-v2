# 指定浏览器与 Agent 视频线路

## 指定浏览器
- 安装版默认共读入口改为用户选择的 Chrome / Edge；选择按数据归属保存，GitHub 授权复用同一选择，不修改系统默认浏览器。
- 只探测标准安装路径，不接收用户给出的可执行路径或命令。所选浏览器不存在时明确报错，不悄悄切换浏览器。
- 共读跳转到本机连接页，一次性配对码只放 URL fragment；连接页不读取聊天/文件，不把配对码发给远端、不写日志。
- 浏览器扩展首次仍需用户安装一次；不能宣称已替用户静默安装。以后点击跳转，再在连接页点击连接即可配对，无需填写地址或复制码；切到目标网页，从扩展点击「共读当前页」开始。未主动开始前零采集。
- 首次安装必须在连接页和应用一级入口可发现：直接提供本机「下载共读扩展」ZIP，不要求寻找程序安装目录。ZIP 只包含固定扩展文件，根目录直接包含 manifest.json；缺文件、符号链接或过大包明确失败，不返回其他电脑文件。
- 连接页显示「下载 → 解压 → 浏览器加载文件夹 → 刷新本页」；浏览器未报告扩展就绪时禁用连接按钮，不能让用户点击无反应。浏览器管理页地址可一键复制，不能声称普通网页能直接打开受限 chrome:// 地址或静默安装扩展。
- 扩展连接页仅允许顶层、精确本机连接路径和扩展自己发出的消息。公网网页不能调用配对/开始权限。沿用 activeTab 权限，不申请所有网站自动读取。
- 原内置浏览器作为明确标注的备用入口保留，不再由菜单默认启动。
- GitHub 官方固定版本二进制只启动它自己的隔离浏览器适配器（子进程 PATH 前缀，不改系统 PATH）；适配器只接受官方 GitHub PKCE 授权地址，并把它交给固定浏览器。官方组件的校验、内存凭据、只读工具和仓库范围不变。

## 找视频工具
- 主 Agent 获得 search_learning_videos（搜索/重搜）与 curate_learning_videos（读取当前候选、按已找到的 URL 筛选/排序）。不依赖模型说一句「已更新」。
- 明确找视频的请求首轮绑定视频检索，明确调整当前视频的请求首轮读取候选，避免联网默认先走普通网页搜索。GrillMe、电脑文件与已启用插件的明确入口优先级不变；否定找视频或视频概念解释不强绑。
- 结果由现有 B站 / 抖音检索产生，继续受应试范围限制；不允许模型编造 URL、封面、标题、播放量，也不能把普通搜索页冒充视频。
- 候选为每用户、每会话的临时状态，版本递增。筛选须传准确 revision，未出现过的 URL / 重复 URL / 旧版本整批拒绝。
- SSE block kind=learning-videos 携带 sessionId、revision 和完整 result；前端整表替换并展示，在新搜索发起后作废旧 HTTP 返回。当前会话以外的推送忽略。
- UI 手动搜索也登记相同会话候选，AI 可读取再调整；没有 session 的旧入口仍兼容。30 分钟过期，最多 128 组候选，不落学习数据库。
- 修改候选只是临时推荐展示，不自动播放、开网页、收藏或更改学习记录，无写入用户数据副作用。

## 悬浮对话滚动
- 历史载入完成 / 切入另一会话 / 悬浮窗重新展开时锚定最新消息，空会话仍从顶部开始。
- 首次载入与窗口恢复也处理异步渲染的高度变化；用户主动上翻后停止跟随，生成中不能抢回滚动位置。

## README 与仓库定位
- 产品本体、程序文件名、数据路径与更新标识保持 StudentBuddy，不做品牌迁移。
- README 展示标题使用用户指定的「学练agent-应试学习,学习ai,题库搜索,练习反馈」，正文自然说明学习 Agent、编程入门、应试范围与反馈流程。
- GitHub 地址名只能含 ASCII 字母/数字/点/横线/下划线；中文标题不等于已重命名远程仓库，地址变更按用户明确选择执行。
- 新更新器验证新旧两个精确仓库发行路径。发布脚本上传到 xuelian-agent，但签名清单暂保留 studentbuddy-v2 的重定向下载 URL，以兼容尚未升级且只认可旧 URL 的安装版；旧仓库名不得被重新占用。不能只更新新清单 URL 而让旧安装拒绝更新。
- 区分通用能力与项目组合设计，截图/动图来自实际前端，演示数据明确标注，不声称首创或学习效果已经验证。
