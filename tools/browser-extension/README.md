# StudentBuddy 网页共读扩展

## 安装一次，以后直接从浏览器开始

1. 在 StudentBuddy「网页共读」或 GitHub 插件卡选择 Chrome / Edge；两处使用同一选择，不改变系统默认浏览器。
2. 首次在共读连接页直接点「下载共读扩展 ZIP」，右键 ZIP「全部解压」。进入 chrome://extensions 或 edge://extensions，开启开发者模式 → 加载已解压的扩展程序 → 选择解压后直接含 manifest.json 的文件夹，把扩展固定到工具栏。无需查找程序安装目录；应用一级入口也保留「打开已安装的扩展文件夹」。安装由用户在浏览器确认。
3. 点击 StudentBuddy「跳转浏览器开始共读」。在浏览器打开的本机连接页点「连接此对话」。扩展自动取得一次性连接信息，无需填地址或复制码。
4. 在该浏览器打开学习网页，点扩展「共读当前页」。返回绑定对话提问，或将定时练习范围切成「正在共读的网页」。未主动开始前不采集。
5. 点扩展「停止并清除临时资料」结束。程序或浏览器重启后，从 StudentBuddy 重新跳转连接即可。

首次安装或更新扩展后，若原连接页没有「扩展已就绪」提示，请重新跳转或刷新页面。5 分钟过期的连接页需从应用重新打开。配对码仅放在地址片段，成功后清除，不交给模型。

高级入口保留手动配对；没有扩展时可用「备用：打开内置共读窗口」，但它不是已有 Chrome / Edge 的标签页。

只需 `activeTab` 临时授权，不请求所有网站自动读取。常驻脚本仅处理本机连接页上的连接按钮，不提取本机其他页面正文。切换所选标签页的站点后需再次选择；同站点跳转继续同步。普通网页顶层正文可用；设置页、跨域 iframe、Canvas、图片/PDF 原生查看器没有可读正文。

正文、当前视野与选区只放在本机服务的内存里，不写入资料库，不读取表单输入、Cookie 或网页存储。你提问或启用网页出题时，检索出的片段会交给已配置的 AI 模型。关闭选中标签页、停止同步或 60 秒收不到快照后清除文字。重新启动应用或浏览器后需重新配对。
