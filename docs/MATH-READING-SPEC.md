# 数学与图解阅读（v0.2.179）

## 阅读目标

在既有像素冒险框架中，数学使用明亮、清晰的解答纸面：公式保留正常数学字形、分数线、上下标和根号；连续推导每一步一行、等号对齐，说明紧邻步骤，结果与验算放在一起。不使用影响辨认的花体替代数学字体，不以新增模型调用修复排版，不改写已输出或落库的数学内容。

## 公式

- 采用 KaTeX，兼容 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 和明确的 math/latex/tex 围栏；代码示例仍按代码显示。美元金额与引用编号不能误判为公式。
- 行内公式融入正文基线，不再显示代码胶囊；独立公式使用解答纸面。支持 aligned/alignedat、分段、矩阵、向量、积分等该引擎覆盖的语法，长公式局部滚动，不撑宽整页。
- 推导用 aligned 环境在等号处对齐；说明可以在步骤外用文字，避免把长解释挤进公式。复制保留原始公式，放大只响应用户点击。
- 流式未闭合公式显示稳定占位；完整后排版，稳定块不因新 token 重绘。未知或无效语法保留源码与说明，不猜算式，不伪造正确结果。历史和流式完成使用同一渲染链。
- 禁止外链、图像及任意 HTML 扩展，限制输入长度、宏展开次数和尺寸；每个公式的宏状态隔离，保留 MathML 可访问表示。数学排版不替代计算验算和已有评分。

## 图解

- Mermaid 完整围栏才启动绘制，运行时按需加载，优先流程、关系、时序与思维图；图面保持白底、深色标签，沿用已有放大、下载和横向阅读。
- 不允许模型更改渲染安全配置、主题脚本或加载外部资源；生成 SVG 仍经过现有白名单净化和纸面处理。输入和图规模受限，错误保留原文。
- 流程图矩形节点的普通标签可在渲染副本中补双引号，防止公式里的括号被当作图语法；不改标签文字、关系、数学数值或保存/复制的原始内容，其它歧义不猜。
- 切换内容、卸载和后到的渲染结果不覆盖新图；重复相同图无需重复绘制，多个图的 ID 独立。绘制过程不阻塞输入或后续文字。

## 求解回复与其它阅读

计算题继续按路线、步骤、结果与代入验算组织；不先报未经推导的数值。提示词推荐标准 LaTeX 对齐语法与 Mermaid 关系描述，真实示意图继续支持 SVG。正式题卡、引用、资料出口、词条高亮和减少动态效果保留。

计算分支将通用偏好的「结论先行/只给结论」改为路线、推导与验算，避免同一轮同时收到两套相反顺序；保留口吻和本轮详略偏好。

检查公式出现在普通段落、列表、表格、学习卡片和题目中的表现；源代码、价格、引用及未知语法保持原文。手机 390/320px 检查局部滚动、足够字号、操作可达和整页无横向溢出。

## 参考与选型

- [KaTeX](https://github.com/KaTeX/KaTeX)：数学排版核心；[支持范围](https://katex.org/docs/supported.html)含多行对齐与矩阵，[配置](https://katex.org/docs/options)有输入信任、尺寸和宏展开限制。直接接入可保留本项目引用与学习卡片。
- [Mermaid](https://github.com/mermaid-js/mermaid)：文字关系自动布局，减少手工坐标；独立加载、受限配置与本项目 SVG 净化配合。
- [Streamdown](https://github.com/vercel/streamdown)：参考闭合块、流式占位与数学/图解插件分工；整体替换还需迁移本项目卡片、词条高亮、引用和主题，本批延续现有稳定块解析。
- [remark-math](https://github.com/remarkjs/remark-math)：成熟的 Markdown 数学插件，适用于统一 remark/rehype 管线；本项目当前为定制解析，采用相同语法约定并独立接入渲染器。
- [MathJax](https://github.com/mathjax/MathJax)：更广的 TeX 与可访问性方案；本批常见教学与多行推导选择 KaTeX，未支持语法如实回退。
- [MathLive](https://github.com/arnog/mathlive)：更适合数学输入与编辑；当前需求是阅读和解答排版，不增加新的公式编辑器。
