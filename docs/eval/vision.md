# 看图核验评测（`image.verify`）

量的是网络配图流程里「视觉模型看一眼」这一步：图是不是要找的东西，图上有没有会泄露答案的文字。

- **数据集**：`tools/eval/datasets/vision-v1.json`，共 46 条。
  - 20 张 Wikimedia Commons 图，由标注者逐张看过。每张图配一个正确主题，再配一个**相近干扰**（线粒体↔叶绿体、有丝分裂↔减数分裂、埃菲尔铁塔↔东京塔……）。
  - 2 条「部分相符」：「富士山」一图的主体其实是飞机；「火星」一图画的是火星车，不是行星。这两张都是真实搜索里冒出来的噪声。
  - 4 条出题泄露样本：图上印着 the chloroplast；周期表上直接标着 26……
- **口径**（`packages/server/src/media/vision-eval-metrics.ts`，有单测）：
  - **误收率**最要紧：相近干扰被判成 yes，错图就会进对话或题目。
  - 误拒只是少一张图，代价小得多。
  - 泄露检出率与泄露误报率分开算；失败留在分母里。
- **运行**：`npm run eval -- vision`（46 次视觉调用）；`--replay <录制件> --check` 零额度重算。
