StudentBuddy 的 Windows 本地安装包，支持 Windows 10/11 x64。

- 下载本页 Assets 中的 `windows-x64-setup.exe` 安装程序，双击安装，从开始菜单启动。
- 内置 Node 运行时，自动打开应用窗口；首次使用在设置中配置自己的 AI 服务商和模型。
- 托盘菜单可以打开应用或退出，重复启动共用一个服务。
- 桌面悬浮球：启动后桌面上出现一只吉祥物（就是应用里那只像素团子，按它的外形裁出窗口，没有底板）。点一下展开成手机大小的窗口，可直接问问题、刷词刷题；按住拖动可换位置并记住。托盘菜单可显示/隐藏它。
- 定时练习：右键吉祥物或使用托盘菜单主动开启，默认每三分钟显示一张独立题卡，直接作答和看解析；可调整间隔、跳过或延后，未答不堆题。
- 网页共读：随安装包提供 Chrome/Edge 扩展，首次在扩展管理页加载，再使用应用中的配对码连接。主动选择的网页正文、划选和视野动态更新绑定对话的临时检索材料，也可作为定时题的范围；停止或断连后清除，不自动存入资料库。
- 应用图标统一为吉祥物（安装包、快捷方式、托盘、任务栏），安装时默认创建桌面快捷方式。
- 学习数据存放在自己的电脑上，升级和卸载保留数据。
- 桌面更新：应用后台检测并准备新版，下载校验完成后提示重启；托盘菜单也可主动检查。升级前备份程序和学习数据库，新版本启动校验失败时恢复旧版。
- 0.2.0 及更早安装版需要手动安装本版一次，随后可使用自动更新。

安装、启动、保存会话、重复启动、停止、升级和卸载均通过隔离环境验证。安装程序尚未做代码签名。

桌面版使用独立的 `desktop-v<版本>` 发布通道。校验值见 `SHA256SUMS.txt`，自动更新清单使用签名校验；安装程序本身尚未做 Windows 代码签名。
