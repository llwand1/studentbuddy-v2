## 复现命令

```bash
# 行数（按包，不含 node_modules）
find packages/<pkg>/src -name "*.ts" -o -name "*.tsx" | xargs wc -l | tail -1
# 测试 + 全绿证明
npm test
# 覆盖率（需 @vitest/coverage-v8，已入 devDependencies）
npx vitest run --coverage --coverage.include="packages/*/src/**"
# 端点数
grep -rE "\.(get|post|put|patch|delete)\(['\"]" packages/server/src --include="*.ts" | grep -v ".test." | wc -l
# 契约类型数
grep -hE "^export (interface|type) " packages/shared/src/*.ts | wc -l
# 提交规范占比
git log --format="%s" | grep -cE "^(feat|fix|chore|docs|refactor|test|ci|perf)(\(|:)"
```
