| 字段 | 说明 |

| **真人验收计数** | 同一**测试目标**每派一次且判「不通过/部分通过」+1；判通过即封存不再计数。**不按**改动次数、提交次数、对话轮次计 |

| 体感记录 | 卡/闪/慢/糊/错字/反直觉/想点错——真人测试独有的价值，不许空 |

## 阈值（与 §10.6 同构，语义不同）

| 真人验收计数 | 强制动作 |
|---|---|
| 1 | 正常改（人对第一次手感有意见，改了再验） |
| 2 | 可以改，但**必须换方案**——禁止同一设计的第二次微调（「再调调间距」不算换方案） |
| **3** | **强制升级**：回需求层重判——要么重做，要么按 §0.14 砍掉。**禁止第 4 次同向微调** |
