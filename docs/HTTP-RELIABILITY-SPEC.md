# HTTP 可靠性与产品维护

## 范围与现状

保留 Express 4、SQLite、本地/云端形态与既有业务错误映射，不在本次迁移 HTTP 框架。现有登录、验证码、公开计数等专用限流和 `tools/backup-db.py` 并非缺失；补齐的是统一入口错误边界、通用请求预算与独立恢复工具。

## HTTP 错误边界

- 所有返回 Promise 的 HTTP 回调必须经 `asyncHandler` 转交拒绝；已有专用包装器须完整消费 Promise。同步异常由 Express 捕获，异步拒绝（包括非 Error 拒绝）统一进入最终四参错误中间件。
- 错误中间件挂在全部路由与静态处理之后。非法 JSON 返回 400、过大请求体返回 413、未知错误返回 500；客户端只见固定可读文案、错误码和服务端生成的请求标识，不返回堆栈、内部路径、请求正文、查询参数或密钥。
- 已开始写响应时不追加 JSON、不重复发送；交由 Express 关闭当前连接。连接已经关闭时不写响应。保留 SSE 业务层已有错误帧与清理逻辑。
- 记录请求标识、方法与固定错误类别，不记录未净化异常消息/堆栈或用户材料。不得用吞掉 `unhandledRejection` 的全局监听掩盖请求错误。
- 防回归：语法检查禁止直接注册 async 回调；类型回归检查覆盖直接/命名 Promise 回调与工厂返回的 async 回调。严格未处理拒绝模式的独立真实服务进程验证失败请求和后续健康请求，包含已发头的流式错误。

## 云端 API 请求预算

- 形态只从 `auth/form.ts` 取值。本地模式不启用云端频控，避免本机任务、扩展与轮询互相误伤；既有专用限流不变。
- 云端 `/api` 在正文解析之前按 Express 解析出的客户端 IP 计通用预算，默认每分钟 600 次。只豁免 OPTIONS、health、status；不信任未经 `trust proxy` 配置的转发头。
- 身份解析后，模型/搜索等高成本入口再按账号（未登录按 IP）计共享预算，默认每分钟 60 次；不是每 URL 一个可绕过的桶，不计请求正文或用户给出的 id。
- 高成本池覆盖重发/热身题、开拓出题、词条提取等实际生成入口；本机已生成图片与 PDF 正常读取不消耗该池，仍受通用预算保护，避免资料浏览挤占生成预算。
- 429 返回固定文案、`RATE_LIMITED`、`Retry-After` 与剩余/重置头；限流响应不缓存。窗口结束可恢复。进程内表有硬容量上限，活跃桶不能通过新键被挤掉；达到容量时拒绝新键，并清理过期桶。
- 此预算仅单进程、重启清零，不声称提供跨实例限流。部署仍依赖正确代理信任链、模型并发闸门与专用身份限制。

## 模块门禁

- shared 与 server 的非测试 TypeScript 源文件均不超过 400 行；web `.ts` 400、`.tsx` 320。shared 无目录级行数豁免。
- 按地图核心/布局/怪物/题目、内容契约/解析、资源目录/范围解析、引导契约/文案/策略、对战实时状态/历史拆分。原有入口保持兼容导出，不改变公开类型、算法结果和持久化数据。
- 新门禁须有隔离改坏测试，实际超长 shared 文件必须报红，而不是仅在文档声称检查。
- 契约指标按类型声明计数，兼容入口的 `export type { ... }` 不重复计入；保持原有声明基线，不因模块拆分虚增能力数字。
- 桌面构建的来源状态比较 HEAD 的规范化内容与未忽略新文件；生成文件的 LF/CRLF 状态噪声不得被误报为源码变更。真实内容差异、新文件及来源核验失败仍需识别，不改写已发布安装包元数据。

## 备份与独立恢复

- 现有 SQLite 在线备份、七日保留与远端同步验证保留。独立恢复工具不需要 Git 远端配置，默认只恢复到不存在的新目标，不直接覆盖运行中的数据库。
- 恢复先以只读方式打开源快照，通过 SQLite backup API 复制至新库，完整性检查和 DELETE journal 后原子发布；不复制陈旧 WAL/SHM。损坏源、符号链接、存在目标明确拒绝，不更改原库。
- 源路径、目标与临时件须经过实际路径核验。失败清理只限本次创建的临时件；不删除用户备份或其他文件。
- CI 在隔离临时目录验证 WAL 中已提交数据恢复、坏源/已有目标/链接拒绝与原库不变；不读取个人安装库，不擅自向远端上传学习数据。
