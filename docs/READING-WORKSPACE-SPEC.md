# 阅读工作台（v0.2.172）

阅读、作答与输入是主要动作。导航和辅助提醒保留入口，正文拥有稳定、独立的空间。

- 桌面工具条的“收起导航”隐藏整个左栏，展开时会话搜索、账号表单和历史列表保持挂载。偏好只记在当前浏览器，存储不可用时仍可操作。手机沿用探索菜单抽屉，不受桌面收起偏好影响。
- 资料架默认收起：搜索 sources 帧只更新小入口和引用，不再跨轮自动弹开。点击“资料 N”、脚注或引用才打开；已主动打开的同会话资料架仍接收 live 更新。
- 重载会话后，从已加载的消息恢复最新可用资料入口，不追加请求。切会话清空旧入口；迟到的历史响应不会覆盖其他会话或 live 帧。
- 资料架的“展开阅读”使用整个主区，“对照阅读”恢复左右对照。对话 DOM 保留，切换不会清空草稿或卸载题卡。关闭资料架恢复对话。
- “专注阅读”临时收起桌面导航、引路灯、督促和话题提醒，回收输入框下方为胶囊预留的高度；会话标题移到工具条，默认出题配比说明与装饰余烬收起，自动等待刷词暂停。正文、输入、题卡、工具确认与错误仍可操作。退出恢复之前的导航偏好；主动展开导航也会退出专注。
- 引路灯移入正文外的工具条，不再覆盖标题；主动推荐仍可由灯的状态和点开菜单访问，工具条不展示额外浮动短提示。

无模型、服务端 API、数据库或搜索费用的新增。正文维持既有最大行宽，空出的横向空间用于居中与留白，避免大屏把一行拉得过长。所有新控件沿用整数网格图标、硬边和主题色。

验证复用既有用例，新增仅 5 例，覆盖导航偏好/草稿保留、临时专注恢复、资料主动开合与预览切回、存储失败以及跨会话历史恢复。真实浏览器另测桌面/手机尺寸、滚动位置、资料展开/对照、入口重载、键盘和减动效。

## v0.2.173：手机回复与可调分屏

- 复习督促和导航、引路灯共用顶部工具条，全局保持挂载，不再在底边预留胶囊的一行。输入区单行起步、随内容增长，手机最多 20dvh，桌面最多 120px；可收起，保留 DOM、草稿和附件。生成时收起输入仍可停止，工具确认入口位于收起区之外。
- 手机同时跟随 VisualViewport 的键盘可见高度，避免软键盘只缩小视觉视口时输入仍停在键盘下面；缩放时不按缩放后的尺寸重排。输入和请求面板限高按实际可见高度计算。
- 打开资料或预览后出现可拖动分界线。桌面左右，手机上资料、下对话；默认资料占 40% / 50%，各自记在本机。拖动保留各区滚动和题卡状态，至少留出可操作空间；方向键调整 5%，Home 复原。资料仍可展开为整页，再回到对照；关闭资料回到完整对话。
- 手机不自动弹等待刷词，仍可通过等待气泡、设置和已收起局的小签手动进入。2 秒定时器触发时复查当前许可，避免离开页面、进入专注或改成窄屏后照旧弹出。
- 确认、方案选择与出题偏好共用一条入口；展开只展示选中的卡，最大 36dvh，内部滚动，不将输入区顶出视口。确认倒计时始终可见，批准必须主动打开并点击原有按钮；不更改后端 60 秒拒绝策略。隐藏的选择卡继续保留自由输入，超时与已收口结果可查看。
- 手机引路灯、复习、刷词、速查、输入菜单与请求卡切换时收起上一工具，避免手动窗口相叠。资料区是对照阅读表面，不属于这组临时工具。
- 趋势提示是复习入口的「新」标记，与逾期红点区分；番茄钟状态保留在入口、详细动作在复习页。手机新怪提醒缩为顶栏入口。手动刷词与速查限高，关闭按钮仍在可见区域。

### 参考与取舍（2026-10-09 查阅官方资料）

| 参考 | 官方说明支持的行为 | 本项目采用与取舍 |
|---|---|---|
| [Notion 手机工作区](https://www.notion.com/en-us/help/workspaces-on-mobile) | 手机导航使用明确入口，编辑工具通过 + 和横向工具条访问，更多选项在菜单 | 辅助入口集中、按需展开；本项目已有聊天输入，不再叠加常驻底部导航 |

“单前台工具、限高卡片与可拖动比例”是本项目据此作出的设计判断，不声称是这些产品的相同实现。代价是手机确认需多点一次查看，但主体回复不会再被自动出现的大卡或练习窗口夺走。真实 Safari / Android 软键盘及系统手势区仍需设备验收，浏览器自动化的矮屏模拟不能替代真机。
