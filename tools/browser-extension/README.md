# StudentBuddy 网页共读扩展

Chrome / Edge：打开扩展管理页，开启开发者模式 → 加载已解压的扩展程序 → 选择本文件夹。

1. 启动桌面版，右键吉祥物（或托盘「定时出题与网页共读」）。也可在主窗口阅读工具栏点「网页共读」。
2. 选择绑定的本机对话，生成 5 分钟有效的一次性配对码。
3. 打开扩展，输入界面给出的本机地址和配对码，点「连接 StudentBuddy」。
4. 在要学习的网页点击扩展 →「共读当前页」。返回绑定对话提问，或把定时出题范围切成「正在共读的网页」。

只需 `activeTab` 临时授权，不请求全站权限。切换所选标签页的站点后要再次选择；同站点跳转会继续同步。普通网页和顶层正文可用；浏览器设置页、跨域 iframe、Canvas、图片/PDF 原生查看器没有可读正文。

正文、当前视野与选区只放在本机服务的内存里，不写入资料库，不读取表单输入、Cookie 或网页存储。你提问或启用网页出题时，检索出的片段会交给已配置的 AI 模型。关闭选中标签页、停止同步或 60 秒收不到快照后清除文字。重新启动应用或浏览器后需重新配对。
