# 普通对话的学习回复

> v1.0 · 2026-10-08 · 活跃。依据桌面 `studentbuddy-learning-agent-design-doc.md` 的研究建议，按现役能力实现。

## 1. 回复形态

解释概念、纠错时，普通讲解先用一句话给核心结论，紧接一行 2–3 个关键词，再按需要展开；计算题开篇用一句求解路线定位方向。分步讲解在每一步连起来说清「做了什么 → 为什么这样做 → 得到了什么、如何接下一步」。这三件事是解释要素，不要求三个小标题或三段；段落/列点和详略仍服从用户的四维回答偏好及本轮明确请求。

计算题不先报未经推导的最终数值，结果和代入验算放在一起；用户明确只要答案时先核对再给。这是模型提示约束，不能替代题卡现有盲解核对。真实模型两次在这道简单方程开篇报错、后文算对，故不机械套用桌面文档的答案先行规则。熟悉概念要直接讲清具体边界/易混淆点，不能只邀请下轮再讲；学习记录的次数与正确率不复述到正文，不宣称已经掌握。

闲聊、工具操作回执、仅出题不套讲解模板。用户选择引导式口吻或 GrillMe 时，先问关键问题，避免先泄露练习答案。已有 SVG/图片/交互演示靠近其解释段；不新增围栏协议或折叠 UI，仍用现有 Markdown 和像素冒险界面，保持「流什么就存什么」。

明确的知识提问按已选回答偏好直接开始，不仅因为「可以讲深或讲浅」先弹路线选择卡；需要选路线、做计划或用户明确犹豫时，沿用现有选择流程，GrillMe 显式开启时仍按模式先问方向。

一次完整讲解后，可以建议用自己的话复述一个关键原因，或进入现有 GrillMe（当前对话范围）练一轮。只选一个下一步，不每轮邀请、不叠加对战与练习邀约。正式题卡继续经 `generate_quiz`，普通对话无强制作答闸门。

## 2. 基于证据调整详略

桌面文档所述深度理解/evo_level 链已在 2026-09-25 下线，三列只是历史库面，无生产判定记录（`DEEP-UNDERSTANDING-SPEC.md` 墓碑）。不能把它当掌握度，也不能推荐已不存在的入口。现役复习已有 FSRS；本批不改调度。

新增 `chat/learning-context.ts`：只对本轮检索的最相关 5 个本人词条读记录，写入独立 `learning` system 段：

- 近 30 天各词条最近 5 道不同题的明确对/错结果；同一题重做只保留最新一次，待核对/坏 JSON/无题标识不算证据。
- 词条复习状态复用 `SELECT_REVIEW_COLS` / `toReviewTerm`，包括个人 FSRS 缩放；记忆可提取度不是理解等级。
- 未解决且挂在该词条上的误区，最多 2 条。

有未解决误区、最近一题错、或已复习且当前可提取度低于 80%：补讲相关前提和错因。至少 3 道不同题、正确率 ≥80%、最新答对且无上述缺口：可减少重复定义，重点讲适用边界/反例，必要时让学习者补一步。其余证据不足：给完整关键步骤，不断言「已掌握」。本批阈值是保守产品规则，不是论文验证的诊断量表。

没有相关词条/没有真实练习或误区记录 ⇒ 不注入此段；读取失败 ⇒ 回空，不增加模型调用或阻断对话。只按本人 owner 读词条、答题和误区；邻居概念与全局能力估计不用于推断本主题掌握。每个词条的名称/误区以 JSON 字符串呈现，并声明只是记录不是指令。

`context-segments.ts` 有序清单同时驱动装配和 token 预算，新增段计入同一个 `systemPromptTokens`；不另写预算。`chat.turn` 提示词版本 3→4，便于按版本比较质量与耗时。

## 3. 研究依据与修正

- [AITutor 实地研究](https://arxiv.org/abs/2607.01692)：12 人部署、7,379 条事件，支持先看结论作为诊断检查点、分层例题与图文关联的设计方向；不是所有用户学习效果提升的随机实验。
- [ICAP 原论文](https://doi.org/10.1080/00461520.2014.965823)：学习者自解释、主动构造有价值；据此提供自愿复述/练习，而非一律扣住答案。
- [Dunlosky 等 2013](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)：自测、分散练习为高效用。桌面文档的 Frontiers 2021 URL 不是该论文，应使用原出版信息；不改变现有复习算法。
- [DeepTutor](https://arxiv.org/abs/2604.26962)：借鉴动态学习记录反哺讲解，技术报告仍在进行中；不复制多代理/Trace Forest 架构，不新增后台模型调用。

## 4. 验收

自动锁：无证据不误判、足够不同题才收缩、同题重复与旧记录不抬高判断、最近答错/误区/遗忘优先、跨用户隔离、缺库不阻断、最多 5 条且素材非指令；出站段与预算同源、多段 system 在 Anthropic 侧完整下发、流式文本与库内文本一致。

真模型：默认概念问、详细推导、带练习记录的熟悉概念、最近答错/误区、简短和引导式偏好；检查无已下线入口、无格式源码泄漏，并回读历史。桌面/手机查看既有 Markdown 与像素样式。全量 check、build、metrics、guard-audit、demo:e2e 后发布。
