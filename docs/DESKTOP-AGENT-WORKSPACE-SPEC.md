# 桌面任务中心、子 Agent 与文件工作区

实现于本地桌面构建 `desktop-v0.2.194`；网站版本独立。这里描述实际执行机制，不把任务列表、后台队列与通用子 Agent 混为一谈。

## 1. 原来有哪些 Agent

### 主对话

主对话使用已有模型网关与工具循环，维护会话历史、材料和学习上下文。同一会话的请求串行，单轮中适合并行的工具调用仍可并行。`update_tasks` 原来主要把计划显示在消息中，并不是独立的可管理任务系统。

### 逐题 Agent 池

作答后的每道题有独立执行、取消和重试控制。每用户最多并发 3 题，分阶段核对答案、分析思考与评价、补充图示；某题失败不会重做所有题目。这是真实执行池，但原来的结果与进度集中在题卡里。

### 后台业务队列

持久化队列处理记忆、维护、练习准备等业务工作，具有尝试次数与重试机制。它不等于一个可以任意委派任务的 Agent，也不复制主对话上下文。

## 2. 新增的通用桌面子 Agent

```text
主对话（会话历史 + 学习工具 + 本机文件工具）
  └─ delegate_task（明确任务、必要上下文、能力）
      ├─ 子 Agent A：独立上下文、模型/工具循环、任务清单
      ├─ 子 Agent B：同上
      └─ 子 Agent C：同上
          └─ 返回状态、结果摘要和错误给主对话

任务中心创建的独立任务 → 同一执行池中的根 Agent
逐题池 / 后台业务队列 → 观察原有真实执行，不启动重复执行器
```

- 不是「换一个角色提示词继续用完整主会话」。子 Agent 只拿委派描述与必要上下文，拥有自己的模型调用、工具结果与进度；主 Agent 必须提供足够的自包含任务说明。
- 使用现有模型配置与 `desktop.agent` 网关用途，选择 explain 角色；任务详情显示实际返回的模型，不提供假装已经运行的前端计时。
- 主对话等待子任务的结果，再继续综合回答。可以在同一轮委派多个独立任务；上限之外进入队列。
- 子 Agent 可用 `desktop_workspace`、`list_files`、`read_file`、`write_file`、`update_tasks`，没有 shell、程序执行、删除或再委派工具。原有主对话学习工具不自动全部开放给子 Agent。
- 每用户并发上限 **3**，待执行队列上限 **20**；一个主任务最多创建 **8** 个一级子 Agent。不支持任意深度递归代理树。
- 单任务描述最多 12000 字符；最多 **8** 轮模型循环，每轮最多 **8** 个工具调用；执行上限 **8 分钟**，单次网关调用另有 120 秒超时。等待许可也计入总执行时间。
- 输出上限 4000 token，历史受 80000 字符与当前模型 token 上下文预算双重约束。文件工具返回进一步收敛并明确标注截断。
- 同一子 Agent 的文件操作顺序执行，防止同一轮并发覆盖。不同 Agent 不提供同一文件事务锁；任务拆分应给各自产物独立文件名。
- 默认创建只读 Agent，用户可选择工作区可写；只读父任务不能产生可写子任务，模型不能自行升级能力。
- 取消父任务会向子任务和正在等待的文件许可传递取消。失败、取消、中断的通用 Agent 可以显式重试，创建新记录并保留旧结果；主对话和题解回原界面重试。
- 工具失败或声明清单仍有未完成项时，不因模型最后说了「完成」就标为成功。保留已有结果和具体错误。

## 3. 文件能力与授权

### 边界表

| 位置 / 操作 | 默认行为 |
|---|---|
| 电脑普通文件和目录 | 可以按任务需要列出、读取；工作区外禁止写入 |
| 当前工作区 | 创建、读取、覆盖文本；覆盖前备份原件 |
| 敏感文件 / 敏感目录 | 对具体规范路径、具体 read / list / write 操作询问一次 |
| 只读 Agent 写入工作区 | 服务端拒绝，不能由模型升级 |
| 执行程序 / shell / 删除文件 | 不提供这些文件工具 |
| 网络路径 / 设备路径 / 备用数据流 | 拒绝 |

这是使用当前 Windows 用户已有权限的**应用与工具层访问约束**，不是修改 Windows ACL、授予管理员权限或绕过系统文件访问控制。未启用 `SB_DESKTOP=1` 的网站部署不会开放文件与子 Agent 路由；桌面 API 仍通过现有回环地址、Host、Origin 与身份边界。

### 工作区

- 默认 `%USERPROFILE%\Documents\StudentBuddy Workspace`，不存在时自动创建。
- 任务中心「文件」页可输入已有文件夹，也可在原生安装版点击「选择文件夹」。必须主动点「应用工作区」或在原生选择后确认设置。
- 禁止把整盘、整个用户目录、系统目录或已知凭据目录直接当工作区。相对路径只能在工作区内；读取区外普通文件需给绝对路径。
- 工作区保存于本机数据库，主窗口与悬浮窗共用。更改工作区后重新检查等待中的操作，不追授原来的写入目标。
- 写入路径检查每个现有组件，拒绝符号链接、目录联接及悬空联接，防止借工作区链接写到区外。路径还拒绝 `..` 相对穿越、Windows 保留设备名、尾随点/空格别名及 ADS。
- 文本用临时文件原子替换；覆盖前备份到本机学习数据目录的 `file-backups`。已有文件超过 256KB 不允许覆盖，要求另存新文件。

### 敏感判断与许可生命周期

- 已知凭据、配置目录，例如 `.ssh`、`.aws`、`.codex`、AppData；`.env`、私钥、密码库、数据库和敏感命名文件先询问，批准前不打开正文。
- 普通命名文本只在本机检查凭据、密钥、身份或财务特征；命中后正文仍被扣留，不先送给模型，直到用户批准。
- 规则识别不是完整语义隐私分类。用户可把任何文件或目录「标为敏感」，目录内文件一并受保护；标记持久化。取消手动标记不会关闭内置规则。
- 许可卡显示规范路径、操作与理由；按钮为「允许一次」和「拒绝」，没有整盘永久许可。每次操作重新申请，5 分钟未处理自动失效，重启也失效。
- 同一任务拒绝过的规范文件不会换别名重复索要。取消任务、断开手动文件请求或授权超时均不会返回内容或继续写入。
- Agent 许可卡说明：允许后必要内容可能发给已配置的模型提供商。手动文件预览只在本机界面显示，不自动提交给 AI。

### 当前支持的文件范围

列出单目录前 200 项，不做递归扫描；读取普通文本，尝试 UTF-8 / GB18030，单次读取最多前 256KB并标注截断。单次 UTF-8 写入不超过 256KB。模型工具另有约 13KB JSON 预算，截断保持有效 JSON；本机预览仍可显示允许的 256KB。

这套工具目前不提取 PDF、Word、Excel 等二进制文档，也不运行文件中的指令。任务结果在中心用纯文本展示，不自动加载结果里引用的远程图片。

## 4. 独立任务中心

主窗口与悬浮窗工具栏中，引路灯旁的 **☷** 方形按钮打开「任务与工作区」。入口不属于消息滚动区，也不依赖某条消息是否挂载。

- **任务**：主对话根任务、父子结构、独立任务、逐题分析和后台任务；可筛选全部、活跃、完成、失败/中断/取消。
- **Agent**：重点查看独立及子 Agent，能力、实际模型、当前阶段、进度、结果和事件记录。
- **文件**：切换工作区、目录浏览、文本预览/编辑、保存和手动敏感标记。
- **机制**：在产品内解释三类执行机制、权限与持久化边界。
- 活跃数量或待许可数量显示为入口角标；许可卡在各页上方可见。打开时每 1.5 秒刷新，关闭时每 4 秒刷新；刷新状态不触发模型调用。
- 任务清单、状态、结果、错误、父子关系和事件存入 SQLite；界面展示最近 200 条任务和最近 20 条后台工作。不是无限历史管理器。
- 服务启动把未结束任务标为「中断」，失效旧许可，不自动重放模型请求或文件写入。守护程序仍恢复服务和界面，用户查看记录后手动重试。
- 收起悬浮球继续保留已经挂载的应用与任务；之前的对话、会话恢复、草稿与崩溃恢复优化同时保留。

## 5. 数据与 API

迁移 v61 新增 `desktop_run`、`desktop_run_event`、`desktop_file_approval`，按 owner 隔离。设置项 `desktop.files.workspace` 与 `desktop.files.protected` 同样按 owner 保存。

基路径 `/api/desktop/workbench`：

| 接口 | 用途 |
|---|---|
| GET `/state` | 工作区、任务、待许可、后台工作与统计 |
| PUT `/workspace` | 主动切换目录 |
| POST `/protected-paths` | 设置 / 取消用户敏感位置标记 |
| POST `/tasks` | 创建真实独立 Agent，返回 202 |
| GET `/tasks/:id` | 结果与事件 |
| POST `/tasks/:id/cancel` / `/retry` | 取消树 / 显式重试通用 Agent |
| POST `/approvals/:id` | 本次允许或拒绝 |
| POST `/files/list` / `/read` / `/write` | 本地预览及工作区保存 |

不存在由模型或前端参数伪造主任务 ID、永久授权或提升 capability 的接口。所有文件读写都走同一服务端策略。
