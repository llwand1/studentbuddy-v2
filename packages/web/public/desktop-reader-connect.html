就在这个浏览器里共读

第一次不用找安装目录，直接下载这份扩展即可。

首次安装 · 只需一次① 下载共读扩展 ZIP
  1. 下载完成后，右键 ZIP →「全部解压」。选解压后的文件夹，不是 ZIP 文件。
  2. 打开浏览器扩展管理页：edge://extensions

    复制后粘贴到地址栏并回车，打开「开发者模式」，点「加载已解压的扩展程序」。
  3. 选择刚才解压的文件夹。选对的文件夹里应直接有 manifest.json。
  4. 把 StudentBuddy 扩展固定到工具栏，回到这里刷新页面。下方会显示「扩展已就绪」。如果连接已过期，从应用重新点击「网页共读」。

已经安装？无需再下载，刷新这页或在扩展管理页重新加载即可。

连接后怎么共读？

在当前浏览器打开要学习的网页 → 点击工具栏 StudentBuddy 扩展 →「共读当前页」。回到 StudentBuddy 提问，网页正文、划选与当前视野会随阅读更新。

安装与开始共读由你在浏览器确认。未点击「共读当前页」前不读取目标网页；仅同步选中的标签页，不访问浏览历史、登录凭据或其他标签页。停止共读即清除临时材料。
