# 视频学习插件与吉祥物邀请

## 个性化现况

「越用越懂你」指用户归属的学习状态更新，不是模型权重训练、自动改代码或未经验证的学习效果承诺。

| 链路 | 现有证据与使用位置 | 限制 |
|---|---|---|
| 回答方式 | answer-style 四维偏好，注入回答与出题 | 明确选择，不等同自动猜懂所有喜好 |
| 跨会话画像 | user_memory；压缩提炼背景/目标/偏好，记忆页可删除 | 自动沉淀主要依赖压缩触发，短对话未必立即提炼；同义冲突尚无完整修订机制 |
| 行为偏好 | 领域与术语提及榜 → memory-digest → 长期画像 | 累计提及不是近期兴趣；不声称因果效果 |
| 学习弱点 | 复习可提取度、AI 阅卷误区，注入相关回答与出题 | AI 诊断可能有误，允许手动解决，复犯重新打开 |
| 难度调节 | adaptive-quiz 基于近期答题事件的能力估计 | 样本不足不建议，目标正确率不是效果保证 |
| 记忆调度 | FSRS-5 的逐词稳定性/难度；30 条有效样本后拟合个人稳定性缩放，新增 20 条再拟合 | 是缩放拟合，不是重新训练全套参数；拟合损失是样本内指标 |
| 练习反馈 | 逐题作答与思考、题目评价、后续调整 | 未具备完整在线 A/B 效果评估和学习计划自动修订 |

本次将上述方向与误区接到视频推荐、桌面单题提示词；不凭空为用户生成兴趣画像。

## B 站内置学习插件

- 使用内置 adapter，不冒充远端 MCP，也不要求用户配置 Token。第三方导入仍只能是 HTTPS MCP；禁止覆盖内置插件。
- 显式启用后，在指定 Chrome / Edge 打开 B 站。此版本使用公开视频信息，不是 B 站账号 OAuth；不访问登录 Cookie、历史、私信或收藏，不更改账号。
- 工具：recommend_videos（方向、真实候选及相关资料）、select_video（规范 BV 链接、公开简介、用户笔记）、quiz_from_video（真实材料的一道练习）。调用走既有插件发现、停用取消、参数校验和审计链路。
- 学习方向优先级：明确关键词 → 当前专注学科 → 已启用应试范围 → 有行为证据的常学领域；无证据要求指定方向，不假装已经了解用户。
- 检索复用视频线路与应试范围，资料复用联网搜索；只有真实命中的链接可推荐，不伪造标题或来源，不自动播放。
- 视频元信息只访问固定公开 API 与规范 BV id，响应有大小和时间上限。失败时可采用同一视频的实际共读页；不得把 API 失败伪装为成功。
- 视频学习状态按 owner 持久化，笔记有长度上限。切换视频同时清除旧笔记；断开清除学习状态。
- 出题优先用户明确提交的字幕/笔记，再采用同视频共读划选，最后视频公开简介。仅有标题或材料不足时拒绝视频内容题，显示补充字幕/笔记的方法；不下载视频、不声称已解析完整声音/画面。
- 材料标记来源和基于何种文字出题，外部内容不作为指令。生成复用既有模型预算、校验及题卡作答持久化。
- Agent 不能提交或更新笔记；用户在学习卡通过独立 notes 入口提交，防止模型编造字幕为自己的题目背书。「相关视频」明确依照已选视频标题，排除该视频本身；更换学习方向的普通推荐不混入旧视频标题。
- 桌面开启网页范围且选定该 B 站视频时可用该学习材料主动出题；页面变化仍遵守旧题不堆积、预备题失效规则。

## 吉祥物主动邀请

- 到点且题目已成功备好时，吉祥物保留球态，在旁边显示「某考点的小题出好了，快来挑战一下吧！」，不自动展开大题卡、不抢焦点。
- 邀请含「挑战一下」「两分钟后」；接受须匹配当前题 id，过期/切换/取消事件不可打开旧题。
- 每题只主动弹出一次；收起、窗口展开、隐藏球、拖动、截图、渲染恢复时清理或暂时隐藏邀请。题目仍可点击吉祥物进入，不丢题、不堆提醒。
- 气泡锚定球与当前显示器工作区，左右/上下翻转及边界钳制，支持 DPI。原 64px 吉祥物裁剪保持，不把气泡裁掉。
- 表情：待挑战兴奋、备题思考、答对庆祝、答错鼓励；符文字形、法阵、粒子与当前状态关联。中文邀请逐字显现及符文闪烁为字符特效。
- 减少动态效果时正文直接显示、动画静止；文本完整可读、操作按钮不随动画移动，隐藏后停止绘制定时器。设置仍默认不启用定时出题。

## 验证

隔离测试覆盖多用户、插件停用、无方向、元信息失败/过大、材料不足、切换清笔记、题目来源、模型中止；前端覆盖启用、推荐/笔记/题卡与邀请不自动展开、接受/延后/过期。
原生测试验证无激活、气泡工作区/DPI 几何、Unicode 逐字与关闭清理；像素字形全部在裁剪区域内。演示使用隔离预置模型/视频数据，明确标注，不使用个人学习内容。
