# 夜行营地入场（v0.2.174）

阅读工作台两侧留白成为夜行营地，中央仍是正文和题目。只在空对话挂载：暗塔、营灯、遗迹与地平线分层显形，篝火点亮后，现场生成并核对的新题经符文聚拢、卷轴展开、题干显形和选项刻入。已有对话的阅读不挂这层图景，发送后随空态卸载。

- `CampfireWorld` 是绝对定位的背景，不改变正文最大行宽、资料比例、输入高度或 DOM。默认不接指针，两个可探索图景按钮接收点击与键盘。营灯与遗迹独立开关，只改变本地视觉状态，不写数据库、不召题、不发请求。
- 空态聊天区域作为宽度容器，实际宽度至少 1160px 才显示两侧按钮；按资料分栏后的可用宽度判断，不能只按整窗宽度。窄屏只保留暗色远景、少量微光和中央题目；专注阅读隐藏图景。
- 指针微视差限制为横向 6px、纵向 4px，取整数像素，一帧最多一次更新；指针静止不循环调度，触屏不视差。离开、页面隐藏与开启减少动态效果时清理；卸载取消回调和监听。
- 页面揭幕约 1.6 秒，题目到达后的凝成约 2.1 秒；不加入网络等待，不延迟开始真实召题。等待中仍可直接输入自己的问题，失败沿用重试状态。每次进入、换题、换范围仍遵守现场新题与撤旧题契约，动画不缓存题或答案。
- 打开已有会话先等归属匹配的历史读取成功，再确认是否为空；SSE 先连接与迟到历史不能冒充空态或触发召题。历史失败展示错误，不用现场题替代旧对话。首次直接提问也等待这道读取门，沿用发送端的历史完成约束。
- 题目凝成默认状态就是清晰终态。全部阶梯式时序，装饰不接指针、不读屏。少量环境微光在两侧低频变化；题干、选项、光束和符文一次结束后静止。可按“直接作答”跳过；不重召题、不清空当前题，焦点回到答案组。减少动态效果初始及中途生效，取消等待作答的动画门控。
- 像素图景沿用站点 token、自绘 SVG 与 CSS，没有新增运行时依赖、外部媒体或自动音频。没有引入 3D 引擎，所有细节是本项目自绘。

## 参考与取舍（2026-10-09）

| 参考 | 官方资料呈现 | 本项目采用 |
|---|---|---|
| [Bruno Simon](https://bruno-simon.com/) | 通过可探索环境与交互对象组织内容，支持鼠标、键盘和触屏 | 两侧成为有回应的环境，正文仍可直接阅读；没有加入驾驶、碰撞或全屏游戏步骤 |
| [Rive 场景应用](https://rive.app/use-cases) 与 [Listeners](https://rive.app/docs/editor/state-machine/listeners) | 交互插画、角色、空态与鼠标/点击驱动的状态回应 | 本地开关与微视差回应输入；借鉴互动节奏，没有使用 Rive 运行时或复制资产 |

这里的暗塔、营灯、遗迹及新题凝成是本项目的设计判断，不声称上述网站有相同像素布局。两个按钮是视觉探索，不承担学习、导航或请求 AI 的动作。真实软键盘和系统手势区的真机验收仍沿用阅读工作台的待办。

验证复用 Welcome 的现场题契约与阅读流程回归，只新增 3 例本地状态测试。另用浏览器验证实际构建产物的分层帧、鼠标/键盘回应、静止时无持续调度、手机/窄栏隐藏互动、跳过入场、现场换题与失败撤旧、旧对话慢加载移除图景、减少动态效果和输入位置。
