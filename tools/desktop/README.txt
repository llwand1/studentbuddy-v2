StudentBuddy Windows 本地版

从开始菜单启动 StudentBuddy，会打开应用窗口。
第一次使用请在设置里配置自己的 AI 服务商与模型。
关闭窗口后，服务仍在托盘运行；右键托盘图标可打开应用或退出。

启动时桌面上还会出现一只吉祥物（悬浮球）。点一下它会展开成手机大小的窗口，可以直接问问题、刷词刷题；按住拖动可以换位置（位置会记住）。托盘菜单可显示/隐藏它，或用「悬浮球回到吉祥物」把它收回原样。

小屏采用紧凑工具栏：探索菜单是引路灯旁的方形按钮，不再重复显示品牌栏。输入框保持在窗口底部；收起再展开不重置对话和草稿，程序重启恢复上次悬浮窗会话。恢复历史、切会话、重新展开时默认显示最新轮；主动上翻后流式回复不抢回滚动位置。服务、窗口渲染或桌面程序异常退出会自动恢复；主动退出不会重启。

引路灯旁的「☷」打开独立任务中心：任务、Agent、文件、机制四页，可看主/子任务进度、逐题分析和后台队列，取消任务或重试失败的独立 Agent。子 Agent 每用户并行上限 3，独立上下文，不再派生下一层。
鼠标移到吉祥物会显示「输入提问 / 截图提问」选项条。输入提问回到原会话；截图可拖动框选，Esc 取消，Enter 整屏，先预览再放入输入框，点击发送才交给配置的视觉模型。主窗口工具栏「▣」也可截图。不会自动上传、保存临时截图或持续采集屏幕；未配置视觉模型会显示配置提示。
电脑普通文件按需只读；默认工作区为 %USERPROFILE%\Documents\StudentBuddy Workspace，可在「文件」页选择已有独立文件夹。工作区内可创建/覆盖文本，覆盖前备份原件；区外不能写入，不提供程序执行或删除工具。当前读取文本最多 256KB，不提取 Office/PDF 等二进制文档。
敏感目录、文件名、正文凭据特征或手动敏感标记触发具体操作许可：「允许一次」/「拒绝」，5 分钟失效，不授予整盘永久许可。Agent 获得允许后的必要内容可能发给你配置的模型。任务与设置保存在本机；程序重启后未结束任务标为中断，不自动重放写入，可查看已有结果后手动重试。

右键吉祥物或托盘「定时出题与网页共读」可开启自动练习：默认每 3 分钟弹一张独立题卡，不用打开小屏应用；间隔可改为 1–60 分钟。题卡不主动抢焦点，做完/跳过后重新计时，也可延后两分钟。展开应用或隐藏吉祥物时不会自动弹题，未做完不会堆题。需先配置本机 AI，或准备当前学习范围的可编译题目蓝图。

网页共读：选择 Chrome / Edge 后，点击跳转就在该浏览器连接当前对话，无需手填地址和复制码。首次由用户在浏览器加载安装目录 browser-extension 扩展；连接后打开目标网页，点扩展「共读当前页」开始。只同步选中页，停止即清除临时材料；内置共读窗口保留为备用。相关片段会送给配置的模型。详见 browser-extension/README.md。

GitHub 使用同一浏览器选择，授权后勾选仓库。找视频支持主 Agent 换词、追加检索、筛选和排序，不能伪造视频来源或自动播放。仓库地址已改为 github.com/llwand1/xuelian-agent，程序名与旧数据路径不变。

支持 Windows 10/11 x64，无需另装 Node 或 npm。应用窗口依赖系统自带的 WebView2 运行时（Windows 11、以及装过 Edge 的 Windows 10 自带）；若运行时缺失，会改用默认浏览器打开并在日志说明原因。
学习数据使用既有 studentbuddy-v2 数据目录，升级和卸载不会删除学习数据。
应用启动后会后台检查桌面更新并下载新版，校验完成后提示重启。也可在托盘菜单选择「检查更新」或「重启更新」。安装前备份程序和学习数据库；新版本未能正常启动时恢复旧版。
0.2.0 及更早版本需要先手动安装一次带更新器的版本，之后即可使用自动更新。
启动日志：%LOCALAPPDATA%\StudentBuddy\desktop.log

项目与源码：https://github.com/llwand1/xuelian-agent
内置运行时和各依赖的许可证位于 runtime/LICENSE 与 node_modules 中。
插件：在「设置 → 插件」选择浏览器后点击连接 GitHub，授权完成再勾选仓库即可使用。Token 方式保留在高级入口。可导入 JSON 声明接入其他 HTTPS MCP 服务，第三方工具每次确认；本版不执行第三方脚本。

0.2.199：共读默认跳转指定浏览器，首次直接在连接页下载扩展 ZIP，解压并加载含 manifest.json 的文件夹即可；不用找程序安装目录。连接后从扩展点击共读当前页。内置窗口保留为备用。题组允许未答完交卷；AI 可验证应试资源并请求确认添加。流程图修复合法配色误拒，失败可重试。
